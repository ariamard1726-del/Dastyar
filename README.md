# دستیار

دستیار حقوقی آفلاین فارسی برای اندروید (Flutter). برنامه هیچ مدل زبانی ندارد و مجوز اینترنت نمی‌خواهد؛ گفتگو را یک وکیلِ قاعده‌محور پیش می‌برد. پاسخ‌ها از متن قوانینِ داخل برنامه بازیابی می‌شوند، با ذکر منبع و ماده. اگر ماده‌ای پیدا نشود، به‌جای حدس‌زدن همین را می‌گوید. قالب‌های پیش‌نویس (مثل شکوائیهٔ چک) فقط پیش‌نویس‌اند و هنوز بازبینی حقوقی نشده‌اند. برنامه وکیل نیست.

## ساختار

لایه‌بندی `lib/` (وابستگی فقط رو به پایین؛ جزئیات در `docs/ARCHITECTURE.md`):

- `lib/core/`: زیرساخت بدون وابستگی به قابلیت‌ها — `persian_text.dart` (لایهٔ یکتای متن فارسی: نرمال‌سازی، ارقام، برش ایمن یونیکد، اعتبارسنجی کد ملی/تلفن، ایست‌واژه و ریشه‌یابی)، `engine.dart` و `models.dart` (بارگذاری موازی قوانین در Isolate، نمایهٔ معکوس BM25F، بازیابی تک‌مرحله‌ای)، `router.dart` (نیت‌های ثابت پرسش)، `conflicts_service.dart` (زنجیرهٔ تعارض مواد)، `replies.dart` (پاسخ‌های ثابت)، `privacy.dart` (رمزنگاری محلی با Android Keystore، `AES-256-GCM`، کلیپ‌بورد حساس و `FLAG_SECURE`)، `history.dart`، `legacy_cleanup.dart` (پاک‌کردن فایل مدل و تنظیمات به‌جامانده از نسخه‌های قدیمی)
- `lib/domain/`: قابلیت‌های حقوقی — `advocate/` (**تنها مسیر گفتگو**: وکیلِ قاعده‌محور با فهم محاوره، پروندهٔ ماجرا، استدلال و استناد به متن ماده؛ ۱۹ موضوع)، `drafting.dart` و `templates.dart` (تنظیم مرحله‌به‌مرحلهٔ سند با ذخیرهٔ موقت رمزنگاری‌شده)، `intent_net.dart` (طبقه‌بند سبک نیت از روی `assets/brain/intent_model.json`؛ مدل زبانی نیست و فقط به وکیل «نظر دوم» می‌دهد؛ آینهٔ پایتون آن در `tools/check.py intent`)، `input_suggestions.dart` (پیشنهاد هنگام نوشتن)، `lawyer/` (`legal_guides.dart` راهنماهای دست‌نوشتهٔ مسائل رایج با استناد به مواد واقعی، `lawyer_voice.dart` تشخیص راهنمای مرتبط و ابراز ناراحتی)، `feedback.dart`، `settings.dart`
- `lib/ui/`: رابط کاربری — `chat_page.dart`، `chat_controller.dart` (فقط وکیل و تنظیم سند را به هم وصل می‌کند و تاریخچه را ذخیره می‌کند) و `chat_models.dart`، صفحه‌های تنظیمات/تاریخچه/درباره و `widgets/chat_bubbles.dart`
- `assets/laws`: متن قوانین با `_meta.json` (منبع یکتای متادیتا؛ `laws_catalog.json` و `data_info.json` با `tools/sync_meta.py` از آن مشتق می‌شوند). `assets/templates`: قالب‌ها. `assets/synonyms.txt`، `relationships.json` (منبع یکتای روابط مواد)، `replies.json`
- `test`: شاخه‌های `advocate/` (رفتار وکیل و نظر دوم طبقه‌بند)، `app/`، `core/`، `domain/`، `drafting/`، `engine/`، `counselor/` و `audit/` (رونوشت گفتگوهای نمونه؛ ورودی آزمایشگاه در `test/lab/probe.txt`). تست برابری پایتون↔دارت در `test/core/parity_test.dart`
- `tools`: ابزارهای پایتون برای اعتبارسنجی یکپارچه (`check.py` با زیردستورهای corpus/assets/meta/intent/parity)، همگام‌سازی متادیتا (`sync_meta.py`)، سلامت‌سنجی (`doctor.py`)، ارزیابی آفلاین (`eval_py.py`) و امضای نسخهٔ انتشار (`setup_release_signing.py`)
- `brain`: آزمایش‌های آفلاین (embedding و مدل کوچک) به‌همراه مجموعه‌های ارزیابی (`brain/eval/`) و استاندارد طلایی برابری پایتون↔دارت (`parity_expected.json`). اپ فقط `assets/brain/intent_model.json` را می‌خواند.

## ساخت و آزمایش

پایتون فقط در زمان ساخت و آزمایش استفاده می‌شود، نه در اجرای اپ.

    python tools/go.py "پیام"     # commit، push، انتظار برای تست، چاپ گزارش کوتاه
    python tools/go.py report     # دوباره چاپ گزارش آخر
    bash tools/build.sh           # ساخت APK امضاشده و دانلود (نیاز به gh)
    python tools/check.py all     # اعتبارسنجی یکپارچهٔ داده/دارایی/متادیتا/مدل نیت/برابری
    python tools/doctor.py        # سلامت‌سنجی و تشخیص وضعیت محیط و گزارش تست

Workflowها در `.github/workflows`:

- `build.yml`: ساخت APK (دستی). با کلید اصلی امضا می‌شود و کلید فقط در Secrets نگهداری می‌شود.
- `test.yml`: بررسی داده‌ها، `flutter analyze` و `flutter test` روی هر push
- `embed.yml` و `train.yml`: آزمایش‌های دستی آفلاین
- `gemini-agent.yml`: پاسخ خودکار به ایشوها و کامنت‌های `/gemini` با کلید محافظت‌شده؛ [راهنمای اتصال، امنیت و حریم خصوصی](docs/GEMINI_AGENT.md)
- `agent.yml`: ایجنت کدنویسی دستی برای پیشنهاد تغییرات در Pull Request

## قواعد

- متن قوانین فقط از منبع رسمی (سامانهٔ قوانین و مقررات جمهوری اسلامی ایران) کپی شود و منبع و تاریخ ثبت شود.
- تستی که داده را ندارد باید قرمز شود، نه بی‌صدا رد شود.
- فایل کلید (jks) هرگز در گیت نباشد و یک نسخهٔ پشتیبان بیرون از GitHub نگه داشته شود.
- جواب غلط با ظاهر موثق بدتر از «پیدا نشد» است.
