# ابزارهای مترادف‌ها

اسکریپت‌های یک‌بارمصرف برای نگهداری `assets/synonyms.txt` (واژه‌های محاوره → واژه‌های متن قانون). هیچ‌کدام در CI اجرا نمی‌شوند؛ همه از ریشهٔ مخزن اجرا می‌شوند.

- `validate_synonyms.py <فایل>`: ردیف‌هایی را رد می‌کند که واژهٔ سمت راستشان در هیچ قانونی نیست.
- `distinct_words.py <شناسهٔ قانون> …`: واژه‌های ویژهٔ هر قانون را فهرست می‌کند.
- `coverage_report.py`: `docs/coverage_report.md` را می‌سازد.
- `new_rows.txt`: ردیف‌های پیشنهادیِ بررسی‌نشده.
