## ۲. چرا برنامه به سؤال جواب نمی‌داد؟

گزارش کاربر: «جواب منطقی نسبت به سوالات کاربر نمی‌دهد و به جای پاسخ‌ها به چیزهای دیگر اشاره می‌کند».

سه ریشهٔ مشخص پیدا شد؛ هر سه از یک الگو می‌آمدند: **میان‌افزارهای مشاوره، پیش از موتور دانش، پیام کاربر را می‌ربودند.**

### ریشهٔ ۱ — دروازهٔ RAG پرسش‌های کوتاه را رد می‌کرد

در `LegalCounselor._ragEligible` این قاعده بود:

```dart
final tokenCount = n.split(' ').where((t) => t.isNotEmpty).length;
if (tokenCount <= 4 && !hasLegalCue) return false;
```

`hasLegalCue` فقط واژه‌هایی مثل «قانون»، «ماده»، «مجازات»، «مهلت» را می‌شناخت. پس «اجاره چیست؟»، «سرقفلی چیست؟»، «مهلت واخواهی چقدر است؟» به RAG نمی‌رفتند و در عوض به‌عنوان پاسخ اسلات یا «گیر کردن» تفسیر می‌شدند. نتیجه: ربات به‌جای پاسخ، همان سؤال قبلی خودش را تکرار می‌کرد.

### ریشهٔ ۲ — پاسخ درست، با یک درخواست بی‌ربط قطع می‌شد

حتی وقتی RAG جواب می‌داد، در حالت «پذیرش عمومی» متن پاسخ با این جمله تمام می‌شد:

```
حالا برگردیم به وضعیت خودت؛ این پرسش هنوز باز است: …
```

یا کارت «موضوع شما کدام دسته نزدیک‌تر است؟». یعنی کاربر مادهٔ قانون را می‌دید و بلافاصله یک سؤال دیگر روی آن می‌نشست؛ حس گفتگو کاملاً از بین می‌رفت.

### ریشهٔ ۳ — بن‌بست «پیدا نکردم»

اگر پرسش در بانک قوانین نبود، تنها پاسخ این بود: «پاسخ این پرسش را در دانش خودم پیدا نکردم. پرسش را با کلمات دیگر بنویسید.» هیچ پیشنهاد، هیچ مسیر ادامه، هیچ سؤال روشن‌کننده‌ای نبود — دقیقاً برخلاف رفتار یک چت‌بات انسانی.

همچنین `Drafting.suggest` روی پرسش‌های حقوقی هم فعال می‌شد و به‌جای پاسخ، «می‌خواهی متنش را بسازم؟» نشان می‌داد.

## ۳. چه چیزی عوض شد؟

### قاعدهٔ تازه: «اول پاسخ، بعد مصاحبه»

```
پیام کاربر
   │
   ├─ پرسش اطلاعاتی حقوقی؟  ──► پاسخ مستند از بانک قوانین (+ چیپ «مشاورهٔ گام‌به‌گام» اگر موضوع تشخیص داده شود)
   │
   ├─ شرح پروندهٔ شخصی؟     ──► مشاورهٔ گام‌به‌گام (رفتار قبلی، حفظ شده)
   │
   ├─ درخواست صریح سند؟      ──► تنظیم پیش‌نویس (فقط با فعل امری یا انتخاب صریح قالب)
   │
   └─ پاسخ کوتاه به سؤال مشاوره؟ ──► همان اسلات پر می‌شود
```

مرز «پرسش اطلاعاتی» و «پروندهٔ شخصی» در `ConversationRouter` تعریف شده است:

| پیام | تشخیص | مسیر |
| --- | --- | --- |
| «اجاره چیست؟» | پرسش اطلاعاتی | RAG |
| «مهلت واخواهی چقدر است؟» | پرسش اطلاعاتی | RAG |
| «برای وصول چک برگشتی چه مدرکی لازم است؟» | پرسش اطلاعاتی | RAG (بدون پیشنهاد سند) |
| «چک برگشتی دارم چه کار کنم؟» | پروندهٔ شخصی (دارم) | مشاوره |
| «حکم غیابی علیه من صادر شده چه کار کنم؟» | پروندهٔ شخصی (علیه من) | مشاوره |
| «مستأجرم خانه را تخلیه نمی‌کند» | جملهٔ خبری | مشاوره |

### تغییرهای دقیق کد

1. **`ConversationRouter` (تازه)** — `isQuestion`، `hasLegalTerm`، `looksLikeLegalQuestion`، `isPersonalSituation`، `isInformationalQuestion` و `nearbyArticleChips`.
2. **`LegalCounselor.shouldStartCounseling`** — اگر پیام «پرسش اطلاعاتی» باشد، مصاحبه شروع نمی‌شود؛ پاسخ می‌گیرد. (دستور صریح «مشاوره» و شرح پروندهٔ شخصی همچنان مشاوره را شروع می‌کند.)
3. **`LegalCounselor._ragEligible`** — پرسش + رنگ حقوقی همیشه واجد RAG است، بی‌توجه به طول جمله. پاسخ‌های کوتاه اسلات («بله»، «۱۰۰ سکه») هنوز هرگز RAG نمی‌شوند.
4. **`LegalCounselor._ragTurn`** — در پذیرش عمومی، پاسخ دیگر با درخواست انتخاب موضوع قطع نمی‌شود. در «پیدا نکردم»، نزدیک‌ترین مواد به شکل چیپ پیشنهاد می‌شوند و یک سؤال روشن‌کننده پرسیده می‌شود.
5. **`ChatController._ask`** — پاسخ‌های بی‌نتیجهٔ چت عادی با متن محاوره‌ای (`rag_miss_lead` + `rag_near` + `rag_clarify`) و چیپ مواد نزدیک جایگزین می‌شوند.
6. **`Drafting.suggest`** — برای پرسش حقوقی (بدون فعل امری) پیشنهاد تنظیم سند نمی‌دهد.
7. **پیام خوش‌آمد** — کاربر را صریح به پرسیدن سؤال دعوت می‌کند، نه فقط به انتخاب دسته.

### نمونهٔ رفتار پیش و پس

| ورودی کاربر | قبل | بعد |
| --- | --- | --- |
| «اجاره چیست؟» | «موضوع شما به کدام دسته نزدیک‌تر است؟» | متن مادهٔ ۴۶۶ قانون مدنی + منبع |
| «مهلت واخواهی چقدر است؟» | ورود به مصاحبه و پرسش دربارهٔ نقش کاربر | متن مادهٔ ۳۰۶ قانون آیین دادرسی مدنی |
| «قانون چک چه می‌گوید؟» (در پذیرش) | پاسخ + «موضوع شما کدام دسته است؟» | پاسخ کامل، بدون قطع کردن |
| «قانون پهپاد کشاورزی چیست؟» | «پیدا نکردم. با کلمات دیگر بنویسید.» | «مادهٔ صریحی پیدا نکردم… نزدیک‌ترین مواد این‌ها هستند… اگر موضوع را یک جمله بگویی…» |
| «برای وصول چک برگشتی چه مدرکی لازم است؟» | «می‌خواهی متن اظهارنامه را بسازم؟» | پاسخ مستند از قانون |
