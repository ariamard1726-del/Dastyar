# ماتریس اولویتِ کاندیدهای پاسخ

این سند از `dev/tools/contracts/priority.json` تولید می‌شود و اولویتِ صریحِ همهٔ
**۲۰ کاندیدِ** خط تولیدِ پاسخ (`lib/domain/advocate/advocate_reply.dart`) را در کلِ
**۱۹۰ جفتِ ممکن** ثبت می‌کند: **۱۱۳ جفتِ هم‌پوشان** (هر دو کاندید می‌توانند روی یک پیام و وضعیت فعال شوند و برندهٔ اعلام‌شده آزمایش می‌شود) و **۷۷ جفتِ جداگانه** (بر اساس پیش‌شرط‌های کد هرگز هم‌زمان فعال نمی‌شوند).

برای بازتولید یا بررسی تازگی:

```
python3 dev/tools/gen_priority.py --check
python3 dev/tools/check.py priority
```
